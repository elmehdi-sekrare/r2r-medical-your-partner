1. Objectif du site

Positionner R2R Medical comme fournisseur professionnel d'équipements médicaux au Maroc.

Le site permet aux visiteurs de découvrir les produits, filtrer le catalogue, préparer une demande de devis, comparer des articles, contacter l'entreprise sur WhatsApp et consulter les informations essentielles avant commande.

2. Identité et expérience générale

Une interface moderne, médicale, professionnelle et orientée conversion.

Design

Interface professionnelle

Design médical moderne avec couleurs de confiance, cartes produits, icônes, sections claires et navigation stable.

Responsive

Compatible mobile et desktop

Pages adaptées aux différents écrans, navigation mobile, filtres catalogue mobiles et mise en page responsive.

Performance

Application React moderne

Projet construit avec Vite, React, TanStack Router et composants réutilisables pour une expérience fluide.

6. Favoris, comparaison et historique

Fonctions d'aide à la décision pour les acheteurs professionnels.

Favoris

Le visiteur peut sauvegarder des produits favoris, les retrouver sur une page dédiée et voir le compteur dans la barre de navigation.

Comparaison

Le visiteur peut comparer jusqu'à plusieurs produits sur des critères utiles : catégorie, type, usage, disponibilité et prix.

Récemment consultés

Les produits visités sont mémorisés localement et affichés dans le catalogue pour faciliter le retour à une fiche produit.

7. Assistant IA

Assistance intégrée pour orienter les visiteurs.

  • Assistant flottant accessible depuis toutes les pages.
  • Interface de chat avec messages utilisateur et assistant.

  • Connexion OpenAI configurée sur le modèle gpt-4o-mini.

8. Multilingue FR / AR

Première couche de traduction pour le marché marocain.

Français

Interface principale en français pour les clients professionnels, cliniques, hôpitaux et distributeurs.

Arabe

Sélecteur AR/FR dans la navigation, sauvegarde de la langue en localStorage et passage automatique en direction RTL.

Les zones principales traduites incluent la navigation, l'accueil, les raccourcis, les sections commerciales et le pied de page.

11. Administration locale

Interface de gestion brouillon pour préparer une future vraie administration.

  • Page admin catalogue.

  • Filtre admin par catégorie.
  • Modification locale du nom produit.

  • Modification locale du prix.
  • Sauvegarde des modifications dans le navigateur.
  • Réinitialisation d'un produit modifié.
  • Réinitialisation de toutes les modifications locales.
  • Export JSON des changements.

Cette administration est un scaffold local. Une version production complète nécessitera authentification, base de données et stockage sécurisé.
